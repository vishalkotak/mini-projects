# mini-projects

A collection of small, self-contained projects built for learning.

## Projects

| Project | What it is |
|---------|------------|
| [rag-agent](./ml/rag-agent) | A retrieval-augmented generation pipeline (load → chunk → embed → retrieve → grounded answer) in a Jupyter notebook. |
| [simd-vector-search](./simd-vector-search) | Vector similarity search with SIMD. |
| [zanzibar-auth-objstore](./zanzibar-auth-objstore) | Zanzibar-style authorization over an object store. |
| [ruststore](./ruststore) | A key-value store in Rust. |
| [zenblog](./zenblog) | A small blog application. |
| [deck](./deck) | A deck/slides project. |
| [bank](./bank) | A toy banking application. |
| [data-generator](./data-generator) | Synthetic data generation. |
| [os-in-thousand-lines](./os-in-thousand-lines) | Following the "OS in 1,000 lines" tutorial. |
| [100-exercises-to-learn-rust](./100-exercises-to-learn-rust) | Working through the 100 Exercises to Learn Rust course. |
| [rust-by-example](./rust-by-example) | Notes and code from Rust by Example. |
